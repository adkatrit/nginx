Audio Engine

Sample-accurate synchronized multi-stem playback with per-stem analysis

StemPlayer Architecture
class StemPlayer { // Core audio nodes audioContext: AudioContext stems: Map<stemId, { buffer: AudioBuffer, // Decoded audio data sourceNode: AudioBufferSourceNode, analyser: AnalyserNode, // Per-stem FFT gainNode: GainNode // Volume control }> masterGain: GainNode // Synchronization startTime: number // AudioContext time when playback started // All stems start at exact same time _createAndStartSources(offset) { const startAt = this.audioContext.currentTime + 0.05; for (const stem of this.stems.values()) { stem.sourceNode.start(startAt, offset); } } }
Key Features
  • ✓ Sample-accurate sync using AudioBufferSourceNode scheduled starts
  • ✓ Pre-decoding all stems before playback eliminates load-time drift
  • ✓ Per-stem AnalyserNodes for independent frequency analysis
  • ✓ Real-time extraction of bass (20-200Hz), mid (200-2000Hz), treble (2000Hz+)
  • ✓ MIDI event scheduling for note-accurate visualization triggers
  • ✓ Individual stem mute/volume controls

Continuous Generation Pattern
// Structures spawn ahead and cleanup behind the camera const SPACING = 8; const AHEAD = 25; const BEHIND = 8; let nextSpawnZ = -50; // In update loop: while (nextSpawnZ < shipZ + AHEAD * SPACING) { spawnStructure(nextSpawnZ); nextSpawnZ += SPACING; } // Cleanup old structures structures = structures.filter(s => { if (s.userData.spawnZ < shipZ - BEHIND * SPACING) { scene.remove(s); return false; } return true; });
