Architecture
Code from Dream
A stem-reactive 3D music visualizer for DeytaDreams. Each track is split into individual stems (drums, bass, vocals, synth, guitar) and each stem's real-time FFT analysis drives a unique Three.js flight scene — reshaping terrain, atmosphere, lighting, and particles.

100% static site. No build step, no bundler, no server-side rendering. Plain JS files loaded via <script> tags. Three.js r182 (WebGPU + TSL) loaded from CDN.
Audio

stem-player.js

Multi-stem synchronized playback via Web Audio API. Per-stem FFT analysis, MIDI scheduling, IndexedDB caching. Stems load progressively: drums first, then bass, vocals, synth, guitar.

Orchestrator

app.js

Main render loop (drawVizThree()). Wires audio analysis to Three.js scenes. Manages playback UI, waveform visualization, playlist, URL hash routing, score/combo HUD, lyrics overlay.

3D World

track-scenes.js

All tracks use buildFlightScene() — a universal flight engine with Preetham sky, star dome, GPU-animated terrain, bird model, and free-rotation camera. Per-track terrain themes drive the look.

Config

themes.js + terrain-themes.js

Per-track visual identity. TRACK_THEMES defines colors, models, background shaders, UI theme. TERRAIN_THEMES defines height functions, vertex coloring, scenery, atmosphere.

Effects

effects-manager.js

Lightning, aurora, god rays, particles, screen shake. Each effect driven by per-stem audio data via manifest routing. Disabled when flight scene is active.

Shaders

backgrounds.js

10 TSL (Three.js Shading Language) animated backgrounds: topo, ocean, nebula, matrix, aurora, forge, sakura, circuit, glacier, savanna. GPU-side animation, audio-responsive uniforms.

Audio Engine
Stem Player
stem-player.js provides sample-accurate multi-stem playback. All stems start at the exact same AudioContext.currentTime with a 50ms scheduling offset for low-latency sync. Each stem gets its own AnalyserNode for independent FFT analysis.

Loading Pipeline

  • Priority order: drums, bass, vocals, synth, guitar, piano, keyboard, other, percussion, backing-vocals, fx, strings
  • Concurrency: 3 stems loading simultaneously
  • IndexedDB cache: DB stem-player-cache, store audio-buffers, keyed by URL
  • Partial load event: emitted after first stem decoded
  • Graceful degradation: works without IndexedDB

FFT Analysis

  • FFT size: 256 bins
  • Smoothing: 0.8 (heavy)
  • Bass: 20–250 Hz → bins 0–10%
  • Mid: 250–2 kHz → bins 10–40%
  • Treble: 2–20 kHz → bins 40–100%
  • Energy: all bins averaged / 255

MIDI Scheduling

  • Format: Standard MIDI (MThd header validation)
  • Parsing: noteOn/noteOff extraction with running status
  • Timing: ticks → seconds via 60 / (bpm × division)
  • Look-ahead: getUpcomingMidiEvents(time, 4s)
  • Event: 'midiNote' → { type, time, note, velocity, channel, stemId }

Events

  • 'stemAnalysis' — per-stem FFT data each frame
  • 'midiNote' — MIDI note events
  • 'loaded' — all stems decoded
  • 'partialLoad' — first stem ready
  • 'progress' — loading progress updates
  • 'ended' — all sources finished playback
  • 'error' — decode/fetch failures
3D World
Flight Engine
buildFlightScene() in track-scenes.js is the universal scene builder used by all tracks. It creates a flyable world with physically-based sky, procedural terrain, and a controllable bird model. The scene is purely time-driven — audio-reactive speed modulation is disabled when the flight scene is active.

Preetham Sky

Physically-based atmospheric scattering via TSL shader nodes. Sun position is driven by song progress: elevation rises from −5° at track start to +5° at track end.

  • Uniforms: turbidity, rayleigh, mieCoefficient, mieDirectionalG, sunPosition, exposure
  • Sun-linked lighting: sun color shifts warm orange → golden; intensity 0.1 → 1.7
  • Tone mapping: ACESFilmic, exposure 0.15 (dark) → 1.0 (bright)
  • Fog: density 0.0018 → ~0.0003 as sun rises; color warms with sunrise

Star Dome + Moon

4600 stars painted onto a canvas texture mapped to a sphere. Fades out as sun rises. Moon tracks opposite the sun (180° azimuth offset).

  • Brightness: power-law distribution (most dim, few bright)
  • Milky Way: concentrated band of faint stars
  • Shooting stars: random chance per frame when darkness > 0.3
  • Moon: sprite with glow, opacity tracks starDarkness
  • Tunable: 26+ parameters via scene-tuner.js (T key)

Bird Model & Camera

GLTF model loaded from ./models/fly-by-bird/scene.gltf. Rotation-based flight with bone animation for neck and body lean.

  • Forward speed: 0.25 (normal), 0.6 (double, hold Space)
  • Yaw: A/D or ←/→
  • Pitch: W/S or ↑/↓ (pitch-driven altitude)
  • Flap lift: Shift
  • Altitude range: 2.0 (min) – 40.0 (max)
  • Camera: third-person follow with look-ahead offset

Chunk System

2D Map-based grid centered on the bird's position. Terrain, water, and scenery chunks spawn/despawn as the bird moves.

  • Chunk size: 80 world units (configurable per theme)
  • Chunk segments: 20–24 subdivisions
  • Chunk range: 5 (circular culling radius)
  • Maps: terrainChunks, waterChunks, sceneryChunks keyed by "cx,cz"
  • GPU animation: themes with gpuAnimated: true use TSL vertex shaders for real-time terrain deformation (e.g., ocean waves)

Height Algorithm: Terms & Conditions

h = base(0.5% freq) × 10 + mid(1.5%) × 6 + fine(4%) × 2.5 + micro(12%) × 0.8 + ridge(1 − |fbm − 0.5| × 2) − valley_carving

Height Algorithm: Data Tide

h = swell(sin × cos × 3.0) + cross(diagonal sines × 2.0) + chop(noise2D × 1.5) + broad(slow sines × 2.0) − 2.0
World Builder
Environments
environments.js provides the EnvironmentMode system — an instanced-mesh world that runs alongside the flight scene (but its updates are skipped when the flight scene is active). It maps each track to an environment type and builds terrain, fog, scenery, and gates.

Note: When buildFlightScene activates, it hides environment visuals (sky sphere, ground plane, instanced scenery, TSL terrain) and disables environment fog.

Visual FX
Effects Manager
effects-manager.js provides a centralized visual effects system driven by per-stem audio data via manifest routing. Each stem declares a visualization.target and effect in manifest.json.

Note: Effects are disabled when the flight scene is active. They only run in the environment-mode rendering path.

Lightning

  • 5 pre-created bolt geometries (TubeGeometry, 15 segments)
  • Random-walk path from Y=30 to Y=−5
  • Trigger: band > (1 − freq) × 0.8 and cooldown > 0.1s
  • Positioned ±40 units from ship
  • Fade: opacity = intensity × (1 − elapsed × 5)

Aurora

  • PlaneGeometry ribbons (60×8, 50 segments)
  • Vertex colors: green → cyan → blue gradient
  • Per-ribbon phase offset for wave animation
  • Y oscillates with sin(time × speed + phase)
  • Opacity: 0.3 × intensity

God Rays

  • ConeGeometry (radius 3, height 40, open-ended)
  • Additive blending, low opacity
  • Positioned above ship, pointing down
  • Intensity driven by stem energy

Particles

  • Points system with per-vertex velocities
  • Size and opacity modulated by audio
  • Burst mode on beat detection
  • Additive blending, size attenuation

Screen Shake

  • Camera X/Y perturbation
  • Triggered on bass hits
  • Exponential decay
  • Configurable via effectsConfig.visual.screenShake

Stem Routing

  • Manifest declares per-stem: target, effect, color
  • Targets: terrain, atmosphere, particles, background
  • Effects: impact, deformation, fog, pulse, burst, trails, glow
  • See Audio Reactivity doc for full details
GPU Shaders
TSL Backgrounds
backgrounds.js provides 10 animated backgrounds using TSL (Three.js Shading Language) — a node-based shader graph that compiles to WGSL (WebGPU) or GLSL (WebGL). No hand-written shader strings. All backgrounds share a common set of uniforms and audio-reactive helpers.

Shared Uniforms

uTime // elapsed time uColor1/2/3 // theme colors (from TRACK_THEMES.backgroundEffect) uAccent // accent color uSpeed // animation speed multiplier uIntensity // visual intensity uScale // pattern scale uAudioEnergy // overall audio energy (0–1) uAudioBass // bass band energy uAudioMid // mid band energy uAudioTreble // treble band energy uBeatPulse // decaying beat pulse (0–1) uSunX/Y // sun position (normalized) uSunSize/Color/Intensity uAudioReactivity // master multiplier for all audio effects

Audio Helpers (TSL Functions)

Waveform Visualizer

Dual-canvas system: sunBackgroundCanvas (sun position overlay) beneath waveformCanvas (stacked stem energy).

  • • Per-stem energy history (400 slots per stem)
  • • Fritsch-Carlson monotone cubic interpolation for smooth curves
  • • Variance amplification: power law (γ=2.0) relative to per-stem mean
  • • Cumulative stacking: each stem's top = next stem's bottom
  • • Draw order: drums, bass, vocals, synth, guitar
  • • Muted stems render at α=0.12, active at α=0.65
  • • Played portion bright, unplayed portion dimmed

Score & Combo

  • • Gate hits: small=100, medium=50, large=25 (base score)
  • • Score = baseScore × comboMultiplier
  • • Combo tiers: 2x (low), 3x (mid), 5x (high), 8x (max)
  • • Rhythm sync: measures APM vs BPM harmonics (0.25x–4x)
  • • Regularity: coefficient of variation of tap intervals
  • • Per-track high scores stored in localStorage
